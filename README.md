## ✨ Features

- **Dynamic Fragrance Switcher**: Seamless 3D bottle transitions with interactive mood and palette adaptation.
- **Sensorial Mood Selector**: Interactive persona selector tailored to custom aromatic profiles.
- **Smooth GSAP Scroll Reveals**: Custom scroll triggers revealing bespoke ingredients, tasting notes, and customer reviews.
- **Ultra-Fast Vite Performance**: Sub-second page loads with optimal asset delivery.

---

## 🛠️ Tech Stack

- **Framework**: React 19 with Vite
- **Motion & Transitions**: Framer Motion, GSAP, Lenis Smooth Scroll
- **Icons**: React Icons
- **Deployment**: GitHub Pages

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/cyber-atharv/fruitivo-luxury-fragrance.git

# Navigate into project directory
cd fruitivo-luxury-fragrance

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.
